Sobre mí

Una base en programación, distintos caminos para desarrollarla

Soy Sergio, titulado en Desarrollo de Aplicaciones Multiplataforma y residente en Sevilla. Durante mi formación y mis proyectos personales he trabajado con programación orientada a objetos, interfaces, persistencia de datos y APIs.

Me interesan especialmente el backend con Java y las aplicaciones Android con Kotlin. También practico desarrollo web, combinando interfaces con servicios y bases de datos. En NexaStock utilizo Spring Boot, React y PostgreSQL; en MascotaSure trabajo con Kotlin, Jetpack Compose y Firebase.

Estos proyectos forman parte de mi aprendizaje, no de experiencia laboral como desarrollador. Los voy mejorando mediante pruebas, revisión de errores y documentación de sus limitaciones. Busco una primera oportunidad junior en backend, Android o desarrollo web, incluido Full Stack, donde pueda seguir aprendiendo y asumir responsabilidades de forma progresiva.

NexaStock Fullstack

Java · Spring Boot · React · PostgreSQL · Docker

Plataforma SaaS Full Stack para la gestión de inventario, clientes y pedidos, desarrollada con backend en Java/Spring Boot, frontend en React con TypeScript, base de datos PostgreSQL y despliegue local con Docker Compose.

Incluye autenticación con JWT, roles de usuario, API REST documentada con Swagger/OpenAPI, arquitectura por capas, dashboard de negocio, control de stock, creación de pedidos, datos demo, tests básicos y flujo CI con GitHub Actions.

  • Java 21
  • Spring Boot
  • Spring Security
  • JWT
  • REST API
  • React
  • TypeScript
  • PostgreSQL
  • Docker
  • Swagger
  • GitHub Actions

Java · Spring Boot · API REST · H2/MySQL

Incluye funcionalidades de negocio como cálculo automático del precio total de la reserva, validación de fechas, control de reservas solapadas, generación automática de tareas de limpieza y exportación de huéspedes a CSV.
